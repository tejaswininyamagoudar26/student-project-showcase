# Application Screenshots Guide

This directory holds visual assets and screenshots for **ProjectHub (Student Project Showcase)**.

When publishing the repository or showcasing it to recruiters and peers, capture PNG screenshots from the live application and save them with the filenames below.

## Recommended Screenshots Checklist

| Filename | Description | Viewport |
| :--- | :--- | :--- |
| `01-homepage.png` | Homepage hero section (*"Discover. Build. Showcase."*), featured highlights, discipline categories, and discovery bar. | Desktop (1920x1080) |
| `02-projects-explore.png` | Projects directory (`/projects`) showcasing live search, category/technology filters, and responsive project cards. | Desktop (1920x1080) |
| `03-project-detail.png` | Comprehensive project detail page (`/projects/[id]`) showing problem statement, proposed solution, GitHub repo button, live demo link, and discussion thread. | Desktop (1920x1080) |
| `04-student-dashboard.png` | Private student workspace (`/dashboard`) showing project counters (Total, Published, Drafts, Likes) and project management table. | Desktop (1920x1080) |
| `05-submit-project.png` | Submission form (`/submit`) with field validation, discipline selection, and cover image upload preview. | Desktop (1920x1080) |
| `06-student-profile.png` | Public student profile (`/students/[id]`) with university affiliation, department, graduation year, verified skills, and published works. | Desktop (1920x1080) |
| `07-admin-portal.png` | Administration panel (`/admin`) displaying platform metrics, moderation queue, user management, and category controls. | Desktop (1920x1080) |
| `08-dark-mode.png` | Dark mode theme across the interface showing high-contrast slate aesthetics. | Desktop (1920x1080) |
| `09-mobile-responsive.png` | Mobile responsive layout showcasing mobile navigation drawer and card grid. | Mobile (390x844) |

## Guidelines for Screenshots
- Use clear browser windows without browser extension icons or cluttered bookmarks bars.
- Ensure sample project data contains realistic engineering descriptions, technologies, and GitHub links.
- Maintain consistent aspect ratios (16:9 for desktop views).
